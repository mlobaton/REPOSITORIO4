# Task Manager con Python y MySQL

Proyecto CRUD de consola desarrollado con Python y MySQL.

Este sistema permite:

- Crear tareas
- Ver tareas
- Actualizar estado de tareas
- Eliminar tareas

---

# Tecnologías utilizadas

- Python 3
- MySQL
- mysql-connector-python

---

# Funcionalidades

## Crear tarea

Permite registrar nuevas tareas indicando:

- título
- prioridad

El estado inicial será:
- Pendiente

---

## Ver tareas

Muestra todas las tareas registradas en la base de datos.

---

## Actualizar tarea

Permite cambiar el estado de una tarea usando su ID.

---

## Eliminar tarea

Permite eliminar tareas usando su ID.
